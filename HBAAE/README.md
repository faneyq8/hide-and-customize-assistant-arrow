# HBAAE

Hide or fade the Single-Button Assistant arrow on both Blizzard action bars and EllesmereUI.

## Features

- Supports Blizzard action bars.
- Supports EllesmereUI action bars.
- Enable/disable toggle.
- Opacity control from 0% to 100%.
- PayPal donation button in the addon settings.
- Saved account-wide settings.

## Settings

Open with:

`/hbaae`

The settings page includes:

- Enable HBAAE
- Arrow opacity
- Restore Defaults
- Donate via PayPal

## Commands

- `/hbaae`
- `/hbaae on`
- `/hbaae off`
- `/hbaae opacity 0-100`
